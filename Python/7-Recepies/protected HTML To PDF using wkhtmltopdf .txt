2. Fixing the "Only First Page/Cut Off" Issue
==============================================
If you run the command above and only get a single page, the website likely uses CSS that forces the body to a height of 100vh or hides overflow. You can override this using the --window-status or JavaScript delays, but the most reliable trick is telling wkhtmltopdf to use print media styles or injecting custom CSS.

Solution A: Use Print Media Styles
-----------------------------------
Many modern sites have print-specific stylesheets that optimize the layout for multi-page printing.
	wkhtmltopdf --print-media-type https://example.com output.pdf
	
Solution B: Force JavaScript to Load (Smart Delay)
-------------------------------------------------
If the page relies on infinite scroll or heavy JavaScript to load all the content, wkhtmltopdf might render too quickly. Give it a few seconds to load everything:
wkhtmltopdf --javascript-delay 5000 https://example.com output.pdf

3. Advanced Settings for Long Pages
===================================
If you are dealing with a massive webpage and want to fine-tune how the pages break, use these helpful flags:

Remove Margins: Prevents content from being clipped at page breaks.
	wkhtmltopdf -T 0 -B 0 -L 0 -R 0 https://example.com output.pdf

Adjust Page Size: If the web page layout looks squished on standard A4, switch to Letter or a custom viewport size
	wkhtmltopdf --page-size Letter --viewport-size 1280x1024 https://example.com output.pdf

If the PDF still only shows one page after trying --print-media-type, the website has strict CSS rules like body { overflow: hidden; }.
You can bypass this by downloading the HTML file locally, removing that specific CSS line from the file, and running:
	wkhtmltopdf local_file.html output.pdf
